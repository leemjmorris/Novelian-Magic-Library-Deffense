# 노벨리안 마법 도서관 디펜스
## 빌드 노트 v0.5.0 | 2025년 12월 12일

---

### 새로운 기능

**유저 정보 시스템**
- 유저 정보 설정 기능이 추가되었습니다
- 상세 프로필 UI가 구현되었습니다
- 프로필 커스터마이징 기능이 추가되었습니다 (사진/프레임 변경)
- 업적 드롭다운 초안 페이지가 추가되었습니다

**Firebase 서버 연동**
- Firebase 저장/불러오기 시스템이 구현되었습니다
- 서버 기반 데이터 관리가 가능해졌습니다

**전투 카드 시스템 개편**
- 전투 카드 선택 UI 및 로직이 개편되었습니다
- 보조 스킬 호환 카드만 표시되도록 개선되었습니다
- 게임 씬 진입 시 카드 초기화 연출이 개선되었습니다

**스테이지별 맵 레이아웃 시스템**
- 스테이지별 맵 레이아웃 프리셋 시스템이 구현되었습니다
- 레이아웃 에디터 도구가 추가되었습니다

**캐릭터 시스템**
- 캐릭터 아이콘이 적용되었습니다
- 캐릭터 애니메이션이 적용되었습니다
- 캐릭터 스크립트가 리팩토링되었습니다

---

### 임시로 처리한 부분

- 스탯 책갈피 제작을 막아두었습니다. 제작 등급 관련해 테이블이 대폭 변경될 예정입니다.
- 로비 화면에 미구현된 버튼이 여러 종 있습니다. 추후 기능 구현 예정입니다.
- 파티 시너지 기능은 이번 빌드에 포함되지 않았습니다.
- 일부 스킬은 너무 강력합니다. 밸런싱은 진행되지 않았습니다.
- 일부 스킬들은 설명과 이펙트가 어울리지 않습니다. 일부 스킬은 에셋이 임시입니다.
- **스테이지별 맵 동적 구성 기능이 작업 중입니다.** 캐릭터 배치 그리드, 보호 오브젝트 개수 및 위치 등을 스테이지마다 다르게 설정하는 기능은 현재 개발 진행 중입니다.

---

### UI/UX 개선

**로비**
- 로비 UI가 개선되었습니다
- 햄버거 메뉴 패널로 기존 메뉴 버튼들이 정리되었습니다
- 메뉴 패널 애니메이션이 추가되었습니다

**프로필**
- 상세 프로필 패널 UI가 구현되었습니다
- 프로필 버튼으로 상세 패널 접근이 가능합니다
- 정보 패널이 스테이지 UI와 연결되었습니다

**전투 UI**
- 전투 카드 시스템 연출이 개선되었습니다
- 스테이지 UI가 개선되었습니다

**기타**
- 인벤토리 UI가 개선되었습니다
- 재화 단위가 한글 표기로 변경되었습니다 (K→1천, M→100만, B→10억, T→1조)

---

### 에러 수정 및 개선

- 게임 씬 진입 시 카드 초기화가 보이는 이슈가 수정되었습니다
- 상세 불명의 에러가 수정되었습니다 (비동기 시스템에 cancellation token 추가)
- UI 머지 후 깨진 이미지가 수정되었습니다
- 머지 후 충돌 이슈가 수정되었습니다
- 씬이 11개에서 4개로 통합되어 관리가 용이해졌습니다 (Title, Lobby, Game, Demo)

---

### 기술적 개선

- 씬 통합 리팩토링이 완료되었습니다 (11개 → 4개)
- 비동기 시스템에 CancellationToken이 추가되어 안정성이 향상되었습니다
- 캐릭터 스크립트가 리팩토링되었습니다
