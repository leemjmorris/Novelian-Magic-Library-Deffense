# 5팀 주간 빌드 6 빌드 결과 보고서

## 테스트 개요
- **테스트 날짜**: 2025년 12월 19일
- **테스터**:
  - 개발팀 명 (이명진, 이재문, 이채빈)
  - 기획팀 명 (김동욱, 김민휘, 김지원)
- **빌드 버전**: 6주차

## 정상 작동 확인 항목

### 파티시너지
- 파티 시너지가 실제 전투에 적용이 됨.

### 도전 던전
- 도전 던전 1 ~ 10 스테이지까지 진행 가능 (밸런싱 미완료)

### 가챠 시스템
- 캐릭터 뽑기를 통해 캐릭터 획득 가능. 중복 캐릭터에 대해선 정수 형태로 아이템 제공 (정수 이미지는 아직 연출 되지 않음.)

### 몬스터 <-> 캐릭터 간 상성
- 상성에 따른 데미지 멀티플라이어 구현 완료.

## 긍정적 피드백

### UI/UX
- 타이틀 씬이 게임에 잘 어울리고 퀄리티 좋게 나온 것 같음.(1팀)
- 완성된 UI 기준으로, 전체적인 게임의 분위기와 UI가 잘 어우러짐(1팀)
- 폰트가 잘 맞는 것 같아서 몰입감에 도움이 된다(6팀)

### 시스템
- 몬스터가 죽었을 때 사라지는 연출이 좋은 것 같다.(1팀)


### 캐릭터
- 사서 디자인과 일러스트가 굉장히 잘 만들어졌다. (6팀)

## 개선 필요 항목

### 책갈피 제작
- 제작 버튼을 아이콘 뿐만 아니라 이름까지 나왔으면 좋겠다.
- 제작 가능한 경우와 불가능한 경우, 버튼 색상 차이를 둬서 정보를 제공했으면 좋겠다.

### 파견 시스템
- 파견을 보낸 후 아이템 획득 버튼을 누르면 어떤 아이템을 획득했는지 정보를 알려주지 않아서 불편하다.
- 보상 패널을 켠 상태로 파견을 보내면 보상 패널이 망가지는 에러
- 지상/지하 선택할 때의 애니메이션 때문에 진행이 바로 되지 않고 애니메이션 재생이 끝날 때 까지 기다려야함.

### 전투 시스템
- 데미지 폰트가 너무 작고 가시성이 좋지 않다.
- 레벨업을 너무 자주해서 귀찮다. 레벨업을 하면 경험치 총량도 늘어나면 좋겠다.
- 몬스터가 소환 될 때 서로 밀어내며 고장나는 현상.
- 스테이지 진행할 때, 스테이지 제한 시간의 존재 이유를 모르겠다.
- 1-2 스테이지부터 깨는게 너무 어렵다.

### 도전 던전 콘텐츠
- 간헐적으로 게임이 멈춤.

### UX
- 전투/도전 콘텐츠에서 나가기 버튼을 우측 위로 바꾸면 좋을 것 같다. (다른 콘텐츠는 우측 위로 되어있음. 통일감 요구)
- 패널이 뜰 때 뒷 배경의 패널을 막지 않아 뒤쪽 버튼이 눌리는 구간이 있다.
- 사서 덱 설정이 되면 덱에 들어있다는 정보를 캐릭터 아이콘에도 표기해주면 좋을 것 같다.
- 로비 씬이 비어있어서 어색하다.
- 책갈피 제작 후, 확인 버튼이 있으면 좋을 것 같다.
- X 버튼 연타 방지를 위해 위치를 다르게 해둔 것 같은데 오히려 통일성이 없어 보인다.

### 인벤토리
- 보관함 내에 아이템이 없을 경우, 그리드 없이 빈공간이 떠있어서 어색해보인다.

### 보상 관련
- 보상 버튼을 눌러도 보상이 들어온건지 아닌건지 모르겠다.

### 밸런싱
- 밸런스, 튜토리얼 등등 자잘한 콘텐츠가 아쉽다. 구현 되었으면 좋겠다.

### 디자인
- 캐릭터 모델링과 실제 일러스트 사이의 괴리가 너무 크다.
- 캐릭터 모델링과 몬스터 모델링이 별로다.
- 이펙트와 캐릭터 애니메이션이 많이 아쉽다.
