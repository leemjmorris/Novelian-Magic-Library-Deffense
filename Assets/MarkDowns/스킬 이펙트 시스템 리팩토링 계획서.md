> **관련 이슈:** [#448 - 스킬 시스템 개선 (밸런싱, 이펙트 교체)](https://github.com/leemjmorris/Novelian-Magic-Library-Deffense/issues/448)

---

## 목표

- SpecialSkillsEffectsPack 에셋을 최대한 활용 (150개+ 이펙트)
- CSV 기반 데이터 + 에디터 툴로 프리팹 매핑
- 에셋 원본 유지하면서 게임 로직 연동
- 기존 ObjectPoolManager 활용

---

## 접근 방식: 래퍼 패턴 (방법 A)

에셋 스크립트를 최소 수정하고, 래퍼 컴포넌트로 게임 로직을 연결합니다.

```
[SkillEffect_FireBall] (새로 만드는 래퍼 프리팹)
├─ SkillEffectWrapper.cs (게임 로직 - 데미지 처리)
└─ Effect_24_FireBall (에셋 프리팹 그대로 자식으로)
    └─ ObjectMove.cs (에셋 스크립트 - 이동만 담당)
```

### 장점
- 에셋 스크립트 재작성 불필요
- 에셋 업데이트 시 호환성 유지
- 에디터 툴로 래퍼 프리팹 자동 생성 가능

## 컴포넌트 상세 설계

### SkillEffectEntry.cs

```csharp
[Serializable]
public class SkillEffectEntry
{
    public int skillId;
    public string skillName;              // CSV에서 자동 로드 (표시용)
    public SkillAssetType skillType;      // CSV에서 자동 로드

    [Header("이펙트 프리팹")]
    public GameObject mainEffectPrefab;   // 메인 이펙트 (투사체/AOE 등)
    public GameObject hitEffectPrefab;    // 피격 이펙트 (선택)
    public GameObject castEffectPrefab;   // 시전 이펙트 (선택)

    [Header("스케일 설정")]
    public float scaleOverride;           // 0 = 전역값 사용, >0 = 개별값

    [Header("동작 설정")]
    public bool useAssetMovement;         // 에셋의 이동 로직 사용 여부
    public bool overrideSpeed;            // CSV 속도값으로 오버라이드
}
```

### SkillEffectWrapper.cs

```csharp
public class SkillEffectWrapper : MonoBehaviour, IPoolable
{
    [Header("런타임 데이터")]
    public int skillId;
    public MainSkillData skillData;
    public Transform target;

    [Header("설정")]
    public float scaleMultiplier = 1f;

    // 에셋 스크립트와 연동
    private ObjectMoveDestroy _assetMover;

    // 이벤트
    public event Action<Collider, Vector3> OnHitDetected;

    public void Initialize(int skillId, Transform target, float scale);
    private void HandleAssetHit(RaycastHit hit);  // 에셋 충돌 감지 연동
    private void ApplyDamage(ITargetable target, Vector3 hitPoint);

    // IPoolable 구현
    public void OnSpawn();
    public void OnDespawn();
}
```

## 에셋 스크립트 연동 방식

### 최소 수정 방식 (옵션 A - 권장)

에셋의 `ObjectMove.cs`, `ObjectMoveDestroy.cs`에 이벤트 한 줄만 추가:

```csharp
// ObjectMoveDestroy.cs에 이벤트 추가
public event System.Action<RaycastHit> OnHit;

void HitObj(RaycastHit hit)
{
    OnHit?.Invoke(hit);  // 이 한 줄만 추가
    // 기존 로직 유지...
}
```

래퍼에서 이벤트 구독:

```csharp
// SkillEffectWrapper.cs
void Awake()
{
    _mover = GetComponentInChildren<ObjectMoveDestroy>();
    if (_mover != null)
    {
        _mover.OnHit += HandleHit;
    }
}

private void HandleHit(RaycastHit hit)
{
    var target = hit.collider.GetComponent<ITargetable>();
    if (target != null)
    {
        DamageCalculator.ApplyDamage(skillData, target);
    }
}
```

## 오브젝트 풀링 연동

기존 `ObjectPoolManager`의 **Key 기반 풀링** 활용:

```csharp
// 이펙트마다 고유 키로 풀 생성
await poolManager.CreatePoolByKeyAsync<SkillEffectWrapper>("Effect_24_FireBall", 10, 50);

// 스폰
var effect = poolManager.SpawnByKey<SkillEffectWrapper>("Effect_24_FireBall", position);

// 디스폰
poolManager.DespawnByKey("Effect_24_FireBall", effect);
```
